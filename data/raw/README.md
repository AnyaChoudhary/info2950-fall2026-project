# Raw source files

These files are unchanged copies of public research releases, downloaded October 15, 2026.

| File | Contents |
| --- | --- |
| `twitter_s1.csv` | PLOS S1 Dataset: 3,000 rows and 17 annotation/identifier fields |
| `twitter_codebook.docx` | Variable definitions, allowed values, and conditional coding universes |
| `twitter_filter_rules.docx` | PLOS S1 Appendix describing original filtering rules |
| `EDTT_public.csv` | Zenodo EDTT v2: 85 rows and 13 public fields |
| `manifest.json` | Original download URLs, retrieval date, and SHA-256 hashes for the four source files |

Sources: [Cavazos-Rehg et al., PLOS ONE](https://doi.org/10.1371/journal.pone.0207506), [EDTT v2, Zenodo](https://doi.org/10.5281/zenodo.19749827), and [EDTT dictionary](https://edenshaveet.github.io/EDTT/).

The Twitter ID is synthetic. EDTT withholds original post identifiers and private transcripts. Public summaries and annotations are still sensitive research material; the report presents aggregates rather than reproducing post summaries.

The manifest preserves the original source links and recorded file hashes for reference. This README is documentation and is not itself a source-data file in the manifest.
