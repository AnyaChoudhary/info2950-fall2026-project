# Notebooks

[INFO2950_Phase_II.ipynb](INFO2950_Phase_II.ipynb) is the executed Phase II notebook. It includes research questions, collection and cleaning, data descriptions and limitations, EDA, two proposed analyses, references, and reviewer questions.

Run the environment setup in the [root README](../README.md), then restart the notebook kernel and run all cells. The notebook discovers the project root from this directory, writes outputs under `data/` and `figures/`. In a fresh Colab session it automatically restores the saved raw files from the pinned GitHub snapshot, so a separate data upload is not required.

The two preregistration statements are written future plans. No hypothesis-test or model-fitting cells for those plans are included.
